A site with consent that actually works.

Visitors choose which cookies to allow. Scripts for analytics and marketing stay blocked until they say yes, and the choice is remembered.

Current consent

Gate your own scripts

Change the script's type to text/plain and add the category it needs. It runs only after that category is allowed.

<script type="text/plain" data-consent="analytics"
        src="https://example.com/analytics.js"></script>

// or react in code
CookieConsent.onChange(c => {
  if (c.analytics) startAnalytics();
});
